# Initialization Usability Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every Hotel Initialization Wizard step operational in Supabase production mode and deploy the verified repair.

**Architecture:** Keep the wizard as an orchestrator over existing repositories. Add only a narrow access-summary endpoint and a forward migration for import-label audit metadata and trusted staging; all workbook parsing remains server-side.

**Tech Stack:** React 19, Next/Vinext route handlers, Supabase Postgres/Auth/Storage/RLS, Node test runner, pgTAP, Vercel.

## Global Constraints

- Do not import employees, training history, CTC/GTC completion, sessions, attendance, feedback, or KPI facts.
- Do not expose service-role credentials to browser code or logs.
- Do not weaken existing RLS.
- Use Chinese-first production copy and the approved Luxury Hotel Operations Console visual system.
- All primary actions must visibly persist, navigate, change state, or show a specific error.
