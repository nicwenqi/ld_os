# Archived Supabase project evidence

This directory preserves the retired Supabase project’s migrations, SQL tests, seed, and
configuration as historical evidence only. `final-acceptance-operator/` preserves the completed
pre-deletion acceptance operator and cleanup implementation as the same kind of evidence. The
project was deleted after the application moved to Better Auth, Neon, and Vercel Blob.

Nothing under this archive is loaded by the runtime, included in active source validation, or
available as a rollback/compatibility path.
